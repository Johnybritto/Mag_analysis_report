# MAG ANALYSIS MASTER RULES

**Status:** Single source of truth for every future Mag Analysis

This file consolidates the existing Mag Analysis framework, large-PDF safeguards, editorial-bias rules, water-theme rules, research add-ons, question-handling rules, evidence rules and final quality controls.

## Authority and execution rule

1. Before starting any Mag Analysis, read this file first.
2. This file is the authoritative rulebook. `README.md`, `WATER_THEME_RULES.md` and `EDITORIAL_BIAS_RULES.md` are supporting/history files only. If there is any conflict, this master file wins.
3. New Mag Analysis rules should be added here so requirements do not become fragmented again.
4. A mandatory section may be concise, but it must not disappear.
5. If a mandatory check finds nothing useful, write the appropriate explicit result such as `No material finding`, `No material correlation identified`, or `Needs external verification`; do not silently omit the section.
6. Do not explain away a missing mandatory section. Before publishing, complete the missing check.
7. Every report must end with `Mag Analysis Completeness Check` confirming that all mandatory sections/checks were covered.
8. If any mandatory item is still missing, the report status is `INCOMPLETE` and must not be presented as a completed Mag Analysis or pushed as a successful final report.

# A. PURPOSE

Mag Analysis is not a magazine summary. Its purpose is to convert a full business-magazine issue into:

- core business and macro themes,
- hard data and evidence,
- projections versus facts,
- business implications,
- direct and second-order beneficiaries,
- hidden themes missed by the obvious reading,
- portfolio relevance,
- water-theme relevance,
- career/technology relevance where meaningful,
- measurable KPIs,
- variant/contrarian views,
- negative signals and avoid traps,
- questions with initial answers,
- Phase 3 candidates,
- cross-issue/project correlations,
- and clear `So What` actions.

Magazine-mentioned stocks are never automatic buys. A magazine can create a research lead; Phase 3 and current external data decide investability.

# B. RULE CLASSIFICATION

## Mandatory
Must be checked in every issue. If nothing material is found, explicitly say so.

## Conditional
Must be included when the issue contains relevant material, rankings, company profiles, funds, sector tables or other applicable content.

## Optional
May be added when it improves understanding but must not replace mandatory sections.

# C. PRE-ANALYSIS COVERAGE AUDIT — MANDATORY

Before synthesising conclusions, establish document coverage.

Report or internally verify:

| Check | Requirement |
|---|---|
| Total pages detected | Must be known/stated |
| Text parsed? | Yes / No / Partial |
| Image-only/OCR-heavy? | Must be identified |
| Contents/index reviewed? | Must be checked |
| Article map created before synthesis? | Yes |
| Page ranges covered? | Must be listed/summarised |
| Ads / low-signal pages separated? | Yes |
| Tables/charts/rankings reviewed separately? | Yes when present |
| External data needed? | Must be clearly marked |

### Full-issue rule

Do not analyse only the cover story, first visible pages or highest-profile article. Review the issue across meaningful chunks such as:

- cover/editorial,
- macro/news,
- company features,
- sector features,
- interviews,
- rankings/tables,
- personal finance/funds,
- technology/career sections,
- columns,
- ads and low-signal material.

### Large-PDF chunking rule

For long, image-based, partially parsed or table-heavy PDFs, analyse in chunks first and synthesise only after the article/page map is complete.

### High-risk extraction areas

Treat tables, charts, rankings, fund holdings, financial metrics and image-heavy pages as high-risk extraction areas.

- Do not invent unreadable numbers.
- Do not infer exact holdings from fund names.
- If a table is unclear, say so.
- Use external factsheets only when exact holdings/overlap are requested.
- Mark externally researched data separately from magazine-sourced data.

# D. STANDARD REPORT STRUCTURE

## 1. Issue Snapshot — MANDATORY

Provide a short 5–7 line overview of what the whole issue is really about.

Do not merely repeat the contents page. Identify the underlying economic/business message connecting the issue.

## 2. Article Map — MANDATORY

Map major articles/topics with page ranges where possible and explain why each matters.

Useful columns:

| Pages | Article / Topic | Signal Level | Why It Matters |
|---|---|---|---|

Separate high-signal research material from filler/PR/ads.

## 3. THEMES & COVERAGE — MANDATORY

Include:

- **Core Thesis**
- **Macro Drivers & Timeliness**
- **Contrarian Take**

The contrarian take must challenge the magazine's main narrative rather than merely agree with it.

## 4. DATA & CLAIMS — MANDATORY

Include:

- **Hard Metrics & Evidence**
- **Projections vs Opinions**

Explicitly distinguish current data from forecasts, scenarios, aspirations, management commentary and editorial claims.

A projection such as `market could reach X by 2030` must never be presented as a current fact.

## 5. BUSINESS IMPLICATIONS — MANDATORY

Include:

- **Strategy & Execution**
- **Roadblocks & Pivots**
- **Winners vs Losers**

Focus on who actually captures economic value and who merely participates in a growing industry.

## 6. RELEVANCE & FRAMEWORK — MANDATORY

Include:

- **Universal Takeaways**
- **Editorial Framing**
- **Rabbit Holes / Deeper Research Areas**

Any question raised here must carry a quick initial answer under the Question Handling Rule below.

## 7. Signal vs Noise — MANDATORY

Separate real research signal from:

- advertisements,
- sponsored/advertorial material,
- awards/event coverage,
- generic leadership praise,
- company PR,
- fashionable narratives without evidence,
- repetitive industry optimism/pessimism.

Use a simple ranking or score where useful.

## 8. Editorial Bias & Reliability — MANDATORY

Every issue gets an explicit overall bias score from **0–100**:

- **0–25:** Low bias
- **26–50:** Moderate bias
- **51–75:** High bias
- **76–100:** Very High bias

Assess at minimum:

1. Source diversity.
2. Missing counterarguments/bear cases.
3. Promotional or advertorial tone.
4. Hard data versus forecasts/aspirations.
5. Selective use of favourable facts.
6. Political/policy advocacy versus evidence-based framing.
7. Systematic bullish/bearish skew.
8. Recency and quality of evidence.
9. Missing stakeholder perspectives.
10. Sponsored/low-signal material being presented as evidence.

For high-impact cover stories, company profiles, rankings, policy articles and Phase 3 candidates, give article-level bias labels when useful: Low / Moderate / High / Very High.

End this section with one of:

- `Bias does not materially change the investment conclusion`
- `Bias weakens confidence but does not invalidate the thesis`
- `Bias materially weakens the thesis — external verification required`
- `Bias is too high to use this article as an investment signal`

## 9. Theme → Sector → Stock Mapping — MANDATORY

Map:

`Magazine Theme → Economic Requirement → Sector → Direct Beneficiary → Second-Order Beneficiary → Possible Listed Stock`

Do not treat an inferred stock as if the magazine mentioned it.

## 10. Hidden Second-Order Beneficiaries — MANDATORY CHECK

Go beyond obvious companies.

Examples:

- Data centres → power, transformers, cables, cooling, water treatment, networking.
- AI infrastructure → servers, distribution, power, cooling, water, security, monitoring.
- Defence drones → sensors, engines, electronics, communications, prime integrators.
- Healthcare growth → medical infra, water reuse, energy management, automation.

If no credible second-order beneficiary is found, say so.

## 11. Hidden Theme / What Most Readers May Miss — MANDATORY CHECK

Identify any overlooked theme, sector or stock chain that emerges only after connecting several articles.

Do not invent a hidden theme just to fill the section. `No credible hidden theme identified` is acceptable.

## 12. Water Theme Correlation — MANDATORY

This section must appear even when the magazine does not explicitly mention water.

### Required water scan

Check direct or second-order implications for:

- water and wastewater treatment,
- desalination,
- sewage treatment,
- industrial water,
- reuse and ZLD,
- high-purity / ultrapure water,
- municipal water infrastructure,
- pumping and water transmission,
- membranes, resins and treatment chemicals,
- EPC,
- recurring O&M/service revenue,
- water policy/public capex.

### Mandatory correlation triggers

When the issue discusses any of these, explicitly test water demand/read-through:

- semiconductors/electronics manufacturing,
- data centres / AI compute,
- power generation,
- chemicals/specialty chemicals,
- pharmaceuticals,
- steel/metals/mining,
- food & beverages,
- urbanisation/housing,
- industrial/manufacturing capex,
- airports/logistics parks/large infrastructure,
- climate/drought/monsoon/groundwater stress.

### VA Tech WABAG — mandatory check

Assess possible relevance to:

- desalination,
- wastewater/reuse,
- municipal/industrial EPC,
- high-purity water,
- O&M/recurring revenue,
- order intake and order quality,
- international/sovereign-funded projects,
- cash flow and receivables,
- valuation/entry when external verification is requested.

### Ion Exchange — mandatory check

Assess possible relevance to:

- industrial water,
- resins/treatment chemicals,
- high-purity/ultrapure water,
- Roha utilisation,
- chemicals margins,
- engineering margins,
- recurring products/services versus project revenue,
- cash flow, receivables and debt.

### Wider peer scan — conditional

When genuinely relevant, scan names such as EMS Ltd, Enviro Infra Engineers, Denta Water, SPML Infra/JWIL and other listed water/environmental infrastructure companies. Do not add peers mechanically.

### Water conclusion

End the section with one of:

- **Positive / actionable correlation**
- **Watch / emerging correlation**
- **Negative / thesis risk**
- **No material water-theme correlation identified**

## 13. Portfolio Relevance — MANDATORY CHECK

Check whether the issue changes the outlook for current holdings/watchlist names, portfolio theme concentration or competing opportunities.

Do not force a connection simply because a stock is owned.

Where external verification is required for current price, valuation, earnings or order book, label it clearly.

## 14. Career / DevOps / Platform Relevance — MANDATORY CHECK

Check meaningful implications for areas such as:

- platform engineering,
- AI infrastructure,
- cloud,
- Kubernetes,
- cybersecurity,
- data centres,
- automation,
- GCC engineering,
- future skill demand.

If nothing meaningful exists, state `No material career/platform-engineering implication identified`.

## 15. KPI Tracker — MANDATORY FOR MAJOR THEMES

Do not track only stock price. Define measurable business variables that prove or disprove each major thesis.

Suggested table:

| Theme | Stock / Sector | KPI to Track | Why It Matters | Disconfirming Signal |
|---|---|---|---|---|

Possible KPIs include:

- order inflow/order book,
- revenue,
- EBITDA margin,
- PAT,
- OCF/CFO-to-PAT,
- receivables,
- inventory,
- debt,
- capacity utilisation,
- ROCE/ROE,
- market share,
- client additions,
- recurring revenue,
- segment mix.

For every major thesis, identify at least one metric that could disprove it.

## 16. Variant Perception / What the Market May Be Missing — MANDATORY CHECK

State:

`Common view → Our alternative/variant interpretation`

The variant must be evidence-based, not contrarian for its own sake.

## 17. Negative Signals / Avoid Traps — MANDATORY

Every bullish theme must be challenged for risks such as:

- weak cash conversion,
- rising receivables,
- debt/leverage,
- low capacity utilisation,
- project delays,
- policy dependence,
- client concentration,
- governance/promoter issues,
- margin deterioration,
- commodity/input risk,
- excessive valuation,
- narrative-driven price action,
- theme already priced in.

## 18. Killer Questions Before Phase 3 — MANDATORY FOR SHORTLISTED STOCKS

For each shortlisted stock, ask the hardest question that must be answered before buying.

Every question must include a quick initial answer.

Required format:

| Stock | Killer Question | Quick Brief / Initial Answer | Why It Matters | Phase 3 Continuation |
|---|---|---|---|---|

## 19. Management / Phase 3 Questions — CONDITIONAL BUT REQUIRED WHEN COMPANY-SPECIFIC RESEARCH EXISTS

Convert magazine insights into questions for annual reports, earnings calls, investor presentations and filings.

Every management question must carry an initial answer/direction.

Useful questions include:

- What percentage of revenue actually comes from the highlighted theme?
- Is growth order-book-led, volume-led, price-led or margin-led?
- Is operating cash flow keeping pace with profit?
- Is the theme already priced into valuation?
- What single metric would disprove the thesis?

## 20. Thesis Backlog — MANDATORY

Classify research outcomes into:

- **Act Now** — only when current verified price/fundamentals/theme/technical entry align.
- **Deep Dive** — strong theme but more work needed.
- **Watchlist** — good theme but valuation/trigger missing.
- **Avoid** — weak balance sheet/governance/poor risk-reward/overhype.
- **Revisit Later** — needs event, correction, result or policy clarity.

The magazine alone cannot justify `Act Now`; that requires current external verification.

## 21. Phase 3 Candidates — MANDATORY CHECK

Shortlist only companies where the issue uncovered something worth deeper analysis.

Phase 3 should verify as relevant:

- business model,
- latest earnings,
- management guidance,
- order book/pipeline,
- margins,
- cash flow,
- receivables/inventory,
- debt/leverage,
- governance,
- valuation,
- support/resistance and entry timing,
- event risk,
- recurring versus project revenue,
- proprietary technology/IP,
- theme priced-in risk,
- single disprove metric.

If no stock deserves Phase 3, say so.

## 22. Cross-Issue / Prior Analysis Correlation — MANDATORY CHECK

At the end, check whether the issue confirms, weakens or contradicts themes found in earlier magazine analyses, Phase 1/Phase 3 work or project research.

Do not claim a correlation unless there is a real thematic/business link.

Useful labels:

- **Reinforces prior thesis**
- **Weakens prior thesis**
- **New angle on existing thesis**
- **Contradicts prior thesis**
- **No material correlation with prior analyses**

## 23. SO WHAT — MANDATORY

End the analytical body with:

- **The Big Idea**
- **60-Second Briefing**
- **Action Items**
- **What to track**
- **What to ignore/avoid**
- **Stocks/themes worth Phase 3**

Keep the distinction between `interesting business` and `good entry at current price` explicit.

# E. QUESTION HANDLING RULE — GLOBAL

Do not dump unanswered follow-up questions.

Whenever a question is posed, provide:

| Question | Quick Brief / Initial Answer | Why It Matters | Continue in Phase 3? |
|---|---|---|---|

Allowed labels:

- **Answered from issue**
- **Initial inference**
- **Needs Phase 3**
- **Needs external verification**

Rules:

1. If the magazine supports an answer, answer briefly.
2. If annual reports, earnings calls, valuations, prices, fund factsheets or filings are required, say so clearly.
3. Phase 3 comes after the initial brief; it does not replace it.
4. Questions guide analysis; they must not become a substitute for analysis.

# F. EVIDENCE, FACT AND CONFIDENCE RULES — GLOBAL

Every material conclusion should be distinguishable as:

- **Magazine fact** — directly stated/visible in the issue.
- **Magazine claim** — stated by author/interviewee but not independently verified.
- **Verified fact** — supported by primary/credible external evidence when researched.
- **Analytical inference** — our interpretation of the issue.
- **Stock implication** — possible listed beneficiary/loser.
- **Promotional/editorial framing** — wording/emphasis that can influence perception.
- **External verification needed** — current price, valuation, holdings, order book, latest results or other data not established by the issue.

Never convert an inference, management aspiration or editorial claim into a verified fact.

### Confidence labels

Where useful:

- **High** — directly visible in article/table/chart or verified primary data.
- **Medium** — supported by several parts of the issue but partly inferential.
- **Low** — OCR/extraction uncertain or external validation required.

---

# G. CURRENT MARKET DATA RULE — GLOBAL

A magazine does not establish today's:

- stock price,
- P/E or valuation,
- technical support/resistance,
- latest order book,
- latest quarterly results,
- mutual-fund holdings,
- current institutional flows.

If these are needed, use fresh external verification and label them separately from magazine evidence.

Do not invent current data from memory or stale report values.

---

# H. INVESTMENT DISCIPLINE — GLOBAL

1. Do **not** include an `Investment Readiness Score` section.
2. Magazine-mentioned stocks are not automatic buys.
3. Always separate:
   - magazine insight,
   - business variable,
   - beneficiary stock,
   - valuation/entry question,
   - avoid trap.
4. Strong stock ideas should move to Phase 3 before an investment decision.
5. Prefer second-order beneficiaries when the obvious stock is already crowded/expensive, but only if earnings exposure is real.
6. Theme excitement is not enough; ask how the company actually makes money from it.
7. For every major bullish idea, identify a disconfirming signal.
8. For every issue, include at least one table with:

| Theme | Stock | KPI to Track | Killer Risk | Phase 3 Trigger |
|---|---|---|---|---|

# I. CONDITIONAL SPECIAL RULES

## Rankings / Top-500 / Large Stock Lists

When the issue contains a large ranking/list and the task is to shortlist companies:

- shortlist only names with a real business thesis,
- avoid overcrowded/hype-only names where possible,
- check momentum but do not chase,
- check valuation comfort with fresh external data before calling something attractive,
- prefer 10–15 high-quality focus names rather than repeating the whole ranking,
- identify hidden/less obvious candidates only when fundamentals justify them.

## Mutual Funds / Portfolio Overlap

When funds are discussed:

- do not assume holdings from fund category/name,
- use current official/fund factsheets for exact holdings when requested,
- identify overlap across funds only from verified holdings,
- separate large-cap holdings inside small/mid-cap funds from the fund's stated category rationale,
- do not fabricate portfolio overlap from incomplete magazine tables.

## Company Profiles / Interviews

Treat management interviews as useful but potentially biased evidence. Cross-check hard claims when they affect investment conclusions.

# L. GITHUB SAVE RULE

When saving a Mag Analysis to GitHub:

1. Produce a usable full report first.
2. Save clean Markdown without broken ChatGPT/internal citation markers.
3. Use the Mag Analysis repository unless another destination was explicitly requested.
4. Fetch the saved file after writing.
5. Verify it is non-empty and includes the required sections plus the `Mag Analysis Completeness Check`.
6. Only then state that the GitHub save succeeded.
7. If verification fails, state `Failed / Not Saved` rather than claiming success.
