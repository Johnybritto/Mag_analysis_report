# Mag Analysis Report

Repository for business-magazine analysis reports and related research.

## Authoritative rulebook

All future Mag Analysis work must begin by reading:

**`MAG_ANALYSIS_MASTER_RULES.md`**

That file is the single source of truth for the complete Mag Analysis workflow, including:

- full-issue / large-PDF coverage audit,
- core report structure,
- evidence and fact-vs-inference rules,
- Signal vs Noise,
- Editorial Bias & Reliability scoring,
- hidden/second-order beneficiaries,
- mandatory Water Theme correlation including WABAG and Ion Exchange,
- portfolio and career relevance,
- KPI tracker,
- variant perception,
- negative signals / avoid traps,
- killer and management questions,
- thesis backlog,
- Phase 3 candidates,
- cross-issue/project correlation,
- SO WHAT,
- final quality gate,
- mandatory bottom `Mag Analysis Completeness Check`,
- GitHub verification rules.

If any older file, prior report format or chat instruction conflicts with the master rulebook, **`MAG_ANALYSIS_MASTER_RULES.md` wins**.

`WATER_THEME_RULES.md` and `EDITORIAL_BIAS_RULES.md` are retained only as supporting/history documents; their active requirements have been consolidated into the master rulebook.

## Maintenance rule

New recurring Mag Analysis requirements should be added to `MAG_ANALYSIS_MASTER_RULES.md` rather than being stored as disconnected rules. The final completeness gate must also be updated whenever a new mandatory requirement is added.
